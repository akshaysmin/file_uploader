# file_uploader
uploads files one by one to a particular website; can be modified to automate any website interactions

Use installer.sh to install prerequisites and programs

> bash installer.sh

snowycat.py is the main program
Use case :
> ./snowycat.py file1 file2 files

To display the browser while program runs :
> ./snowycat.py -d file1 file2 files

auth.info should be filled with credentials.
